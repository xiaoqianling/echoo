# Echoo Project Refactoring Plan

This plan outlines the steps to refactor the existing `echoo` project into a pnpm monorepo, separating frontend and backend, and extracting shared types and UI components.

## 1. Monorepo Initialization
1.  **Create Workspace Structure**:
    -   Create `pnpm-workspace.yaml` defining `apps/*` and `packages/*`.
    -   Create `apps` and `packages` directories.
2.  **Move Projects**:
    -   Move `client` directory to `apps/client`.
    -   Move `server` directory to `apps/server`.
3.  **Update Package Names**:
    -   Update `apps/client/package.json` name to `@echoo/client`.
    -   Update `apps/server/package.json` name to `@echoo/server`.

## 2. Create `@types/echoo-api` Package
1.  **Initialize Package**:
    -   Create directory `packages/types`.
    -   Initialize `package.json` with name `@types/echoo-api` and `private: true`.
2.  **Extract Types**:
    -   Copy shared interfaces from `apps/client/src/shared/types/index.ts` to `packages/types/src/index.ts`.
    -   Configure `tsconfig.json` for the package.
    -   Export types in `package.json` (`main`, `types`).

## 3. Create `@rei-design/solid` Package
1.  **Initialize Package**:
    -   Create directory `packages/ui`.
    -   Initialize `package.json` with name `@rei-design/solid` and `version: 0.0.1`.
    -   Add `solid-js` as a peer dependency.
2.  **Extract Components**:
    -   Move generic components from `apps/client/src/shared/components` to `packages/ui/src/components`.
        -   `ToastNotification` (renamed to `MessageNotification` to avoid confusion or kept as is).
        -   `ConfirmDialog`.
        -   `AemeathBackground`.
    -   Move associated `styles.scss` files.
3.  **Configuration**:
    -   Configure `vite.config.ts` to build the library (optional but recommended for "publish" requirement) or configure `package.json` to point to source (easier for monorepo dev). I will set up a basic build configuration.
    -   Ensure styles are properly exported or bundled.

## 4. Integrate & Refactor Code
1.  **Update Client (`apps/client`)**:
    -   Add dependencies: `@types/echoo-api` and `@rei-design/solid` (using `workspace:*`).
    -   Update imports to use the new packages.
    -   Remove the extracted files from the source tree.
    -   Fix any broken paths in `styles` or `imports`.
2.  **Update Server (`apps/server`)**:
    -   Add dependency: `@types/echoo-api` (using `workspace:*`).
    -   (Optional) Update DTOs/Entities to implement interfaces from `@types/echoo-api` to ensure type safety.

## 5. Verification
1.  **Install Dependencies**: Run `pnpm install` in the root.
2.  **Build**: Build packages and apps to ensure no errors.
3.  **Run**: Start backend and frontend to verify functionality remains intact.
